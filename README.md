# 🏎️ 3D Supercar Showroom & Neon Underglow Customizer (Three.js / WebGL)

An interactive **3D Automotive Showroom Configurator** built with **Three.js (WebGL 2.0)**, Tailwind CSS, and ES6 JavaScript — featuring metallic body paint swatches, neon underglow lighting toggles, spinning alloy rims, and smooth 360° turntable camera controls at 60 FPS.

👉 **[Launch Live 3D Supercar Showroom](https://newtechportal.com/projects/3d-cyber-car-showroom-customizer/preview)**  
📦 **[Download Complete Source Code (.ZIP) & Docs](https://newtechportal.com/projects/3d-cyber-car-showroom-customizer)**

---

## ✨ Key Features
- **Real-Time Paint & Underglow Configurator:** Switch body paint finishes, wheel accents, and cyberpunk neon underglow colors on the fly.
- **360° Turntable Orbit & Zoom:** Drag with mouse or touch to inspect the 3D supercar from every angle.
- **Zero-Build Frontend Setup:** Self-contained HTML5, Tailwind CSS, and ES6 JavaScript — runs directly in any modern browser.
- **Responsive Desktop & Mobile UI:** Clean glassmorphic HUD overlay adapted for both widescreen monitors and smartphones.
